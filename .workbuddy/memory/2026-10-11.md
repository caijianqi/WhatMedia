## mpv 协议两个真坑（写错不报错，只会静默失效）

1. **`request_id` 是命令对象的顶层字段**，不是 command 数组的元素。
   原实现把它 push 进数组 → mpv 当参数处理 → 响应永远带不回同一个 id → 轨道列表永远读不出来。
   已改 `encode_async` 为顶层字段，并加回归测试。
2. **`observe_property` 逐条发**，不用批量多属性形式（版本支持不一致）。
另：`end-file` 的原因在 `reason` 键而不是 `data`，`MpvEvent` 因此单开 `reason` 字段 ——
否则"播完了"和"解不动了"在上层看起来一样。
